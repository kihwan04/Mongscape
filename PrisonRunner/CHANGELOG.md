# 변경 기록

## 1.0.0 (출시 준비 중)

첫 정식 출시 버전입니다. 전시용 데모를 일반 플레이어용 Windows 게임으로 정리했습니다.

### 출시 빌드
- **빌드 분리:** 배포용 Release 빌드와 검수용 Dev 빌드를 나눴습니다. Release 빌드는 Development 옵션 없이 만들고, 처음 실행하면 전체 창 모드로 시작합니다.
- **검수 기능 차단:** 자동 검수·캡처·녹화용 실행 인수는 Dev 빌드에서만 동작합니다.
- **전시 모드 제거:** 개발자(전시) 모드와 운영자 키(`Ctrl+Shift+F12`, `Ctrl+F10`)는 Release 빌드에서 동작하지 않습니다. 예전 설정에 개발자 모드가 켜져 있어도 실행할 때 꺼집니다.

### 계정과 개인정보
- **회원가입 동의:** 만 14세 이상 확인, 개인정보 수집·이용, 민감정보(얼굴 특징값) 수집·이용을 각각 필수로 동의받습니다. 항목마다 수집 내용, 목적, 저장 위치, 보유기간을 보여 줍니다.
- **동의를 거부하면:** 회원가입과 얼굴 로그인만 쓸 수 없고 게스트로 플레이할 수 있습니다.
- **개인정보 처리방침:** `PRIVACY_POLICY.md`를 추가했습니다(소스에서는 `docs/PRIVACY_POLICY.md`).
- **서버 동의 버전:** 얼굴 서버가 새 동의 문구를 `account-v3`로 기록합니다.

### 화면
- **크레딧:** 로그인 화면과 메인 메뉴에서 크레딧과 외부 리소스 라이선스를 볼 수 있습니다.
- **버전 표시:** 로그인 화면과 메인 메뉴 오른쪽 아래에 버전을 표시합니다.

### 배포
- **ZIP 구성:** 배포 ZIP에 실행 안내, 개인정보 처리방침, 변경 기록, 외부 리소스 라이선스 원문을 넣습니다.
- **배포 검사:** Release 빌드가 아니거나 처리방침이 완성되지 않았으면 ZIP을 만들지 않습니다.
