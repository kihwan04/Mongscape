# Mongscape 개인정보 처리방침

- 시행일: 2026년 11월 19일
- 운영자: 명지전문대학 컴퓨터공학과

Mongscape(몽스케이프)는 웹캠과 키보드로 하는 Windows 운동 러너 게임입니다. 이 방침은 게임과 게임이 연결하는 얼굴 계정 서버가 어떤 개인정보를 왜, 얼마나 처리하는지 설명합니다.

## 1. 회원가입 없이 플레이할 때 (게스트)

게스트 플레이는 서버에 아무 정보도 보내지 않습니다.

- **웹캠 영상:** 몸동작 인식은 게임을 실행한 PC 안에서만 처리합니다. 영상과 사진은 저장하거나 전송하지 않습니다.
- **이 PC에 남는 정보:** 설정(몸무게, 화면·소리 설정 등)과 이 PC의 랭킹(이름, 점수, 거리)이 Windows 사용자 폴더에 저장됩니다. 게임을 지우거나 해당 폴더를 지우면 삭제됩니다.

## 2. 처리하는 개인정보와 목적 (회원)

회원가입은 만 14세 이상만 할 수 있으며, 아래 항목마다 따로 동의를 받습니다.

| 구분 | 항목 | 목적 | 보유기간 |
| --- | --- | --- | --- |
| 개인정보 (필수) | 닉네임, 몸무게, 기본 플레이 방식, 칼로리 목표, 플레이 기록(점수·거리·칼로리·동작 횟수·플레이 시간), 코인·해금 아이템, 튜토리얼 완료 여부, 가입 시각, 동의 버전 | 회원 식별, 기록·랭킹·상점 제공 | 회원 탈퇴 시까지 |
| 민감정보 (필수, 별도 동의) | 얼굴 특징값: 얼굴 사진에서 계산한 숫자 벡터 | 얼굴 로그인 시 본인 확인 | 회원 탈퇴 시까지 |
| 로그인 세션 | 세션 토큰의 해시값 | 로그인 유지 | 로그인 후 8시간 또는 로그아웃 시까지 |

- **얼굴 사진:** 가입과 로그인 때 촬영한 사진은 특징값을 계산하는 데만 쓰고 서버에 저장하지 않습니다. 화면에 보여 주는 얼굴 이미지는 응답에만 담기고 저장되지 않습니다.
- **얼굴 인식의 한계:** 사진·영상 위조를 막는 기능이 없으므로 금융 등 보안 인증 용도로 쓰지 않습니다.
- **요청 기록:** 서버는 요청 내용(사진, 토큰, 계정)을 로그에 남기지 않습니다. 과도한 요청을 막기 위해 접속 IP 주소를 서버 메모리에서만 잠시 사용합니다.

## 3. 동의를 거부할 권리

동의를 거부할 수 있습니다. 거부하면 회원가입과 얼굴 로그인을 이용할 수 없지만, 게스트로 플레이할 수 있습니다.

## 4. 파기

- **탈퇴:** 게임의 **내 정보 → 회원 탈퇴**를 누르면 운영 데이터베이스에서 얼굴 특징값, 계정, 기록, 세션을 즉시 삭제합니다.
- **백업:** 장애 복구용 데이터베이스 백업은 매일 만들고 14일이 지나면 자동 삭제합니다. 그래서 탈퇴한 정보도 백업에는 최대 14일 남아 있다가 삭제됩니다. 백업은 복구 외의 목적으로 쓰지 않습니다.
- **파기 방법:** 전자 파일은 복구할 수 없는 방법으로 삭제합니다.

## 6. 이용자의 권리

언제든 다음을 할 수 있습니다.

- **열람·정정:** 내 정보 화면에서 닉네임, 몸무게, 칼로리 목표, 기본 플레이 방식을 확인하고 고칠 수 있습니다.
- **삭제·동의 철회:** 내 정보 화면의 회원 탈퇴로 할 수 있습니다.
- **그 밖의 요청:** 게임에 접근할 수 없거나 다른 요청이 있으면 아래 연락처로 알려 주세요.

## 7. 안전성 확보 조치

- **전송 구간:** 게임과 서버 사이 통신은 HTTPS로 암호화합니다.
- **접근 통제:** 서버 관리 접속은 키 인증만 허용하고, 데이터베이스는 외부에 열지 않습니다.
- **최소 저장:** 세션 토큰은 해시값만 저장하고, 얼굴은 사진 대신 특징값만 저장합니다.
