# Mongscape 1.0.0

웹캠 앞에서 몸을 움직여 달리는 Windows 운동 러너 게임입니다. 웹캠이 없으면 키보드로 플레이할 수 있습니다.

> 이 문서는 GitHub 릴리스 본문으로 쓰입니다(`Tools/Distribution/publish_github.ps1`). 출시 전 확인 순서는 [출시 체크리스트](RELEASE_CHECKLIST.md)를 따릅니다.

## 다운로드와 실행

1. `Mongscape-Windows-x64.zip`을 내려받아 전체를 압축 해제합니다.
2. `StartGame.cmd`를 더블클릭합니다. 실제 게임은 `Game/Mongscape.exe`입니다.
3. **얼굴 로그인**, **회원가입**, **게스트 플레이** 중 하나를 고릅니다.

`SHA256SUMS.txt`로 내려받은 파일이 손상되지 않았는지 확인할 수 있습니다.

- **필요한 환경:** Windows 10/11 64비트. Unity나 Python은 필요 없습니다.
- **웹캠 (선택):** 전신·상체 플레이에 씁니다. 영상은 PC 안에서만 처리하고 저장하거나 전송하지 않습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| A/←, D/→ | 레인 이동, 수레에서 몸 기울이기 |
| C | 갈림길 가운데 선택 |
| Space | 점프 |
| S/↓ | 숙이기 |
| W/↑ | 하이니(무릎 높이 들기) |
| F1 / F3 | 설정 / 성능 표시 |

## 회원과 게스트

- **회원:** 얼굴로 로그인하고, 코인을 모아 아이템을 해금하며, 통합 랭킹에 오릅니다. 만 14세 이상만 가입할 수 있습니다.
- **게스트:** 가입 없이 바로 플레이하고, 기록은 이 PC 랭킹에만 남습니다.
- **개인정보:** 회원가입 때 얼굴 특징값(사진이 아닌 숫자)을 별도로 동의받아 저장합니다. 자세한 내용은 ZIP 안의 `PRIVACY_POLICY.md`를 확인하세요. 탈퇴는 게임의 **내 정보 → 회원 탈퇴**에서 할 수 있습니다.

## 변경 내용

ZIP 안의 `CHANGELOG.md`를 확인하세요. 사용한 외부 리소스와 라이선스는 게임의 **크레딧** 화면과 `THIRD_PARTY_NOTICES.md`에 있습니다.
